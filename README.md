# Interview Practice Bot (PS31)

Students lack mock interview practice. This bot generates 5 role-based questions, asks them one at a time, scores each answer with feedback, and shows a final summary.

## Run
```
pip install -r requirements.txt
# create .env with GROQ_API_KEY=your_key (free key at console.groq.com)
streamlit run app.py
```

Stack: Python, Streamlit, Groq API (Llama 3.3 70B).
